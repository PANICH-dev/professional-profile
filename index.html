Business Systems Analyst | Full Stack Developer | System Analyst

มุ่งเน้นการวิเคราะห์ความต้องการทางธุรกิจ (Business Requirements) ปรับปรุงกระบวนการทำงาน (Process Improvement) และออกแบบระบบสารสนเทศ (Information Systems) เพื่อพัฒนา Enterprise Web Applications, Automation Systems และ BI Dashboards ที่ช่วยเพิ่มประสิทธิภาพการดำเนินงาน พร้อมขับเคลื่อนการตัดสินใจด้วยข้อมูล (Data-Driven Decision Making)

💼 ประสบการณ์และความรับผิดชอบหลัก

  • Business Process Improvement: วิเคราะห์ความต้องการทางธุรกิจ (Business Requirements) ศึกษากระบวนการทำงานปัจจุบัน (As-Is Process) และออกแบบกระบวนการทำงานใหม่ (To-Be Process) เพื่อเพิ่มประสิทธิภาพการดำเนินงาน
  • Requirements Gathering & System Analysis: รวบรวมและวิเคราะห์ Requirement จากผู้บริหารและผู้ใช้งาน พร้อมออกแบบ Workflow และจัดทำ Functional Specification สำหรับการพัฒนาระบบ
  • Enterprise Web Development: ออกแบบและพัฒนาระบบ Custom Web Application เต็มรูปแบบ (Designed and Developed) ครอบคลุมทั้ง Frontend และ Backend RESTful API พร้อม Deploy ระบบขึ้นใช้งานบนระบบคลาวด์ระดับสากล (Vercel Cloud)
  • Data Modeling & Database Design: ออกแบบฐานข้อมูล (Data Model), Entity Relationship Diagram (ERD) และโครงสร้างข้อมูลให้รองรับการสเกล พร้อมวางมาตรฐานการจัดเก็บข้อมูลด้วย SQL (PostgreSQL)
  • Data Integration & Automation: พัฒนาระบบ Automation (ETL) และเชื่อมโยงข้อมูลระหว่างหลายแหล่ง เพื่อลดการทำงานซ้ำซ้อน ลดข้อผิดพลาดจากการคีย์ข้อมูล และเพิ่มความรวดเร็วในการดำเนินงาน
  • Business Intelligence (BI) & Dashboards: พัฒนา Dashboard บน Looker Studio สำหรับติดตาม KPI, Operational Performance และข้อมูลเชิงบริหาร (Executive Dashboard) แบบ Real-time
  • UAT & Stakeholder Management: ดำเนินการทดสอบระบบ (User Acceptance Test), ดักจับและแก้ไขปัญหา Error ในระบบ (Debugging) ด้วยตัวเอง เพื่อตรวจสอบความถูกต้องของข้อมูลก่อนนำระบบขึ้นใช้งานจริงบน Production

System Interfaces

Intuitive User Interface & Experience

ออกแบบหน้าจอโดยยึดผู้ใช้งานเป็นศูนย์กลาง (User-Centric) เปลี่ยนกระบวนการทำงานที่ซับซ้อนให้กลายเป็น Web App ที่ใช้งานง่าย สบายตา และมีประสิทธิภาพสูงในทุกแผนก

Executive Dashboard

ศูนย์กลางข้อมูลสำหรับผู้บริหาร สรุปสถิติ KPIs การทำงาน การเงิน และภาพรวมองค์กรแบบ Real-time

  • ติดตามเป้าหมายรถเข้า-ออก และรายได้รายวัน/เดือน
  • Data Visualization ที่ออกแบบมาให้อ่านค่าง่ายและตัดสินใจได้ทันที

SA Operations Board

หน้าต่างสรุปงานสำหรับทีม Service Advisor (SA) เพื่อประเมินสถานการณ์รถในศูนย์บริการ และติดตามงานค้าง (Active Jobs)

  • สรุปงานค้างแยกตามสถานะ และยอดปิดบิลรายเดือน
  • ตารางจัดการรถจอด สามารถปรับสถานะ ERP และส่งต่อแผนกได้รวดเร็ว

Smart Appointment Calendar

ปฏิทินนัดหมายแบบภาพรวม ช่วยให้ทีม SA บริหารจัดการพื้นที่จอดรถในศูนย์ และลดปัญหาการรับงานเกินความจุ (Overcapacity)

  • แสดงยอดรถนัดเข้าจอด, เป้าซ่อมเสร็จ, และนัดส่งมอบรายวัน
  • ดีไซน์สไตล์มินิมอล ช่วยให้อ่านค่าง่าย วางแผนรับคิวงานใหม่ได้แม่นยำ

Repair Station Tracking

ระบบติดตามคิวงานซ่อมตามสถานี (WIP Tracking) ช่วยให้หัวหน้าช่างมองเห็นคอขวด (Bottleneck) ของงานได้ทันที

  • จัดกลุ่มสถานะงานทั้ง 12 สถานีด้วย Color-Coded
  • แจ้งเตือนรถที่ซ่อมล่าช้า (Overdue) ป้องกันงานหลุด

Finance & Billing Center

แดชบอร์ดสำหรับแผนกบัญชี เพื่อติดตามสถานะการวางบิล และประเมินตัวเลขทางการเงินแบบแยกหมวดหมู่

  • แยกตัวเลขงานที่รอจัดการ และงานที่ออกบิลแล้วชัดเจน
  • อินเตอร์เฟซแบบมินิมอล ช่วยลดความเครียดในการจัดการตัวเลข

Security & Admin Panel

ระบบบริหารจัดการสิทธิ์ผู้ใช้งาน (Access Control) และฐานข้อมูลตั้งต้น (Master Data) สำหรับผู้ดูแลระบบ

  • ควบคุมสิทธิ์การเข้าถึงเมนูต่างๆ แบบแยกรายบุคคล (Role-based)
  • จัดการฐานข้อมูลพนักงาน สาขา และข้อมูลระบบจากจุดเดียว
